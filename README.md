# 📝 To-Do List App

A simple and responsive **To-Do List Application** built using **HTML, CSS, and JavaScript**.
This app helps users manage daily tasks efficiently with features like adding, completing, deleting, and saving tasks using Local Storage.

🔗 **Live Demo:** https://to-do-app-js-xi.vercel.app

---

## 🚀 Features

* ✅ Add new tasks
* ✅ Mark tasks as completed
* ✅ Delete tasks
* ✅ Data stored using Local Storage
* ✅ Responsive UI
* ✅ Simple and clean design

## ⚙️ How It Works

1. Type your task in the input field
2. Click the **Add** button
3. Tasks appear in the task list
4. Click a task to mark it completed
5. Click the ❌ icon to remove a task
6. Tasks remain saved even after refreshing the browser using Local Storage
